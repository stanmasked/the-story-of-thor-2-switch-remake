# The Story of Thor 2 — Stage 55: альтернативный запуск Saturn без оригинального BIOS

Дата: 22.10.2026.

## Решение проблемы Mednafen

Для Stage 54 подтверждено: ISO оригинальной игры валиден, имеет регион E, 52 224 сектора по 2048 байт, но запуск через Mednafen заблокирован отсутствием приватного BIOS mpr-17933.bin и самого эмулятора. Полный CD с возможными дополнительными CD-DA-дорожками также пока не восстановлен.

Stage 55 вводит **альтернативный экспериментальный путь через RetroArch + Yabause (libretro)**. Официальная документация ядра Yabause прямо указывает, что:
- Saturn BIOS является необязательным (доступна HLE-эмуляция системных функций);
- поддерживается загрузка содержимого с расширением .iso напрямую, помимо .cue и других форматов;
- предусмотрена настройка `yabause_force_hle_bios` (enabled/disabled), действующая после перезапуска ядра;
- совместимость HLE BIOS ниже, чем оригинальной прошивки.

Основания: https://docs.libretro.com/library/yabause/ и https://docs.libretro.com/guides/cli-intro/.

**Следовательно, не нужно сначала получать BIOS или создавать CUE только ради первой попытки загрузки через Yabause.** Это убирает два потенциальных препятствия для первой экспериментальной проверки, однако реальный запуск игры и корректность звука/графики пока не доказаны.

## Что добавлено

Новый `tools/stage55_yabause_hle_launch_readiness.py`:

1. Проверяет приватный исходный ISO по прежней закреплённой SHA-256, проверяет загрузочный заголовок и ISO9660.
2. Принимает необязательные *точные локальные пути* к установленному frontend RetroArch и `yabause_libretro.so`; проверяет, что это регулярные нессылочные файлы подходящего размера с заголовком ELF. Frontend должен иметь право исполнения.
3. Не запускает бинарные программы, не загружает динамические библиотеки, не ищет и не скачивает BIOS или игры.
4. При наличии обоих файлов создаёт приватный массив аргументов запуска без оболочки: `retroarch -L /private/cores/yabause_libretro.so "/private/The Story of Thor 2.iso"`.
5. Сохраняет приватный список действий и возможную команду в новый файл с правами 0600, запретом перезаписи и симлинка. В публичном выводе находятся только безопасные статусы наличия зависимостей, без приватных имён файлов.
6. Никогда не утверждает, что игра загрузилась, что ELF-файлы совместимы с хостом или что RAM/VRAM уже считаны.

## Команда приватной проверки

Для установленного Linux RetroArch и локального ядра Yabause:

```sh
python tools/stage55_yabause_hle_launch_readiness.py \
  --iso-private "/private/The Story of Thor 2.iso" \
  --retroarch-private "/usr/bin/retroarch" \
  --yabause-core-private "/private/cores/yabause_libretro.so" \
  --host-display-present \
  --output-private "/private/stage55.private-yabause-launch.json"
```

При отсутствии эмулятора разрешается не передавать оба параметра. Инструмент всё равно проверит ISO, сохранит диагностический план, но отметит, что компоненты запуска отсутствуют.

Если ядро доступно, RetroArch запускают **локально** через приватную команду из выходного файла. В Quick Menu → Core Options необходимо включить *Force HLE BIOS*, а затем перезапустить ядро/содержимое. Нужен живой графический сеанс. В текущем контейнере RetroArch и ядра Yabause нет; сеть системного пакетного менеджера недоступна (проверка deb.debian.org дала DNS error). Поэтому реальное выполнение этой команды здесь **не осуществлено**.

## Важные ограничения

- `local_binary_looks_usable=true` подтверждает только файл с ELF-заголовком и, для frontend, исполняемые права. Не гарантирует совместимость ABI, нужные библиотеки, поддержку Vulkan/OpenGL или возможность загрузить конкретную игру.
- **HLE BIOS экспериментален:** если именно The Story of Thor 2 не загрузится, это не доказывает, что исходный ISO испорчен. Нужно повторить с оригинальным BIOS в Mednafen или другом точном Saturn-эмуляторе.
- Прямая загрузка ISO Yabause не восстанавливает CD-DA-аудио, отсутствующие дорожки или субканальные данные исходного диска.
- Никакие коммерческие BIOS, оригинальная игра, дампы памяти и скриншоты не добавляются в GitHub. В CI используются только искусственные образы и проверочные ELF-заголовки.
- Приватная команда запуска должна исполняться только пользователем или разрешённым локальным процессом; этот этап сознательно не выдаёт проверку файла за успешный старт эмулятора.

## Тесты и дальнейший план

Добавлено **34 синтетических теста**: контроль структуры ISO, отсутствие необходимости BIOS/CUE, наличие/отсутствие двух бинарных файлов, ELF-заголовки, проверки прав, корректный `argv`, несовпадение ISO SHA-256, опасные пути, приватный режим 0600 и невозможность ложного подтверждения исполнения. Ветка остаётся Draft; `main` не меняется.

Далее: на окружении с Yabause и RetroArch выполнить первый настоящий запуск HLE. Если он работает — захватить лог запуска и RAM/VDP1, после чего переходить к трассировке Stage53 и сверке Stage52. Если не работает — документировать точную ошибку загрузки и вернуться к оригинальному BIOS/полному образу CD.
