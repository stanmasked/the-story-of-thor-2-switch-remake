# The Story of Thor 2 — Stage 06: статистика по целевым окнам

**Дата:** 21.10.2026. Анализ выполнен локально на приватном ISO Sega Saturn `MK-81302`, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. В публичный репозиторий не передавались исходные окна данных, изображения или другие игровые ресурсы.

## Цель

Проверить, различаются ли данные по адресам, которые содержат четыре кандидатных 16-битных поля: два в восьмибайтовых элементах и два в шестибайтовом заголовке каждой записи. Для десяти контейнеров, строго соответствующих Stage 04, измерены окна длиной 8, 16, 32, 64 и 128 байт в третьей секции.

Всего проверено **32 862 элемента и 3 730 заголовков записей**. Все целевые окна размером 128 байт укладываются в соответствующую третью секцию.

Тенденция для полей элементов сохраняется на всех пяти размерах окна: поле A указывает на значительно более разнообразные данные, а поле B — на повторяющиеся и часто нулевые последовательности. Два поля заголовка записи указывают на окна, которые по статистике ближе к более разнообразному полю A, чем к нулевому полю B.

## Интерпретация и ограничения

Эти результаты совместимы с гипотезой, что разные поля ссылаются на разные типы данных третьей секции. Например, одна ссылка может указывать на более плотный блок данных, другая — на разреженный блок или сопутствующий ресурс. Однако статистика **не доказывает**, что поля являются указателями, что данные представляют спрайты, или что установлен какой-либо формат пикселей.

Это ещё не декодирование спрайтов. Не подтверждены формат пикселей, размеры изображений, палитра и порядок сборки кадров. Случайное отображение байтов не будет считаться восстановленной графикой.

## Инструмент и проверка

Добавлен `tools/stage06_target_window_probe.py`. Он выдаёт только агрегаты статистики и не записывает содержимое окон или точные смещения. `tests/test_stage06_target_window_probe.py` содержит 10 тестов на синтетических данных.

Локальная проверка всего набора: **54/54 теста успешно**, `compileall` завершился без ошибок. GitHub Actions для PR Stage 06 должен подтвердить удалённую проверку отдельно.

Повторный запуск на приватной копии:

```bash

python tools/stage06_target_window_probe.py "/private/The Story of Thor 2.iso" -o stage06.json
```
