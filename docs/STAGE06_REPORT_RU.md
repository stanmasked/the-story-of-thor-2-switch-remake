# The Story of Thor 2 — Stage 06: проверка масштаба кандидатных смещений

**Дата:** 21.10.2026. Анализ выполнен локально на приватном ISO Sega Saturn `MK-81302`, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. В публичный репозиторий не передавались исходные окна данных, изображения или другие игровые ресурсы.

## Цель

Предыдущий анализ обнаружил четыре поля, значения которых совместимы с адресами третьей секции. В Stage 06 сравнил два способа интерпретации каждого 16-битного поля:

- `raw_bytes`: значение поля используется как байтовое смещение;
- `units_of_8`: значение умножается на 8 перед обращением к третьей секции.

Для каждого варианта исследованы окна размером 8, 16, 32, 64 и 128 байт. Ни один вариант пока не объявляется доказанным.

*Энтропия дана в битах на байт. Статистика описывает только окна по кандидатным адресам; она не определяет тип данных.*

## Что это говорит о формате

**Элемент A, масштаб ×8** — перспективная гипотеза: все 32 862 элемента дают доступное восьмибайтовое окно, а 32 859 дают доступное окно в 128 байт. Адреса при таком толковании естественно выровнены на 8 байт, и наблюдается больше уникальных окон, чем при прямом байтовом смещении. Это согласуется с тем, что поле может хранить смещение в восьмибайтовых единицах.

Но вариант с прямым байтовым смещением также остаётся в пределах третьей секции для всех элементов. Поэтому масштаб ×8 — **сильная гипотеза, а не установленный формат**.

Для поля B и двух полей заголовка прямое байтовое смещение выглядит более согласованным: при умножении на 8 появляется заметно больше выходов за границы. Поля могут иметь разные представления, но это также требует подтверждения.

## Инструмент и проверка

`tools/stage06_target_window_probe.py` теперь проверяет оба масштаба для четырёх полей и явно считает покрытие/выходы за границы. Отчёт содержит только агрегаты; исходные окна и точные смещения не экспортируются.

`tests/test_stage06_target_window_probe.py` содержит **11 тестов на синтетических данных**. Полный локальный набор: **55/55 теста успешно**, `compileall` завершился без ошибок. GitHub Actions должен подтвердить удалённую проверку отдельно.

```bash
python -m unittest discover -s tests -v
python tools/stage06_target_window_probe.py "/private/The Story of Thor 2.iso" -o stage06.json
```
