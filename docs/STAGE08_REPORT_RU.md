# The Story of Thor 2 — Stage 08: кандидатный просмотрщик текстур

**Дата:** 21.10.2026. На приватном локальном ISO Sega Saturn `MK-81302` проверен первый ненулевой текстурный адрес из `P0.BIN`. В публичный репозиторий не добавлялись исходные фрагменты, изображения или палитры.

## 1. Локальный просмотрщик

Добавлен `tools/stage08_texture_preview.py`. Он:

- находит восьмибайтовый элемент в выбранном контейнере;
- трактует первое поле как кандидатный адрес в единицах по 8 байт;
- берёт байты только до следующего адреса, на который ссылаются элементы того же контейнера;
- строит локальное PNG-превью для выбранного предположения о 4, 8 или 16 битах на пиксель;
- использует отладочную серую шкалу и делает индекс 0 прозрачным для 4/8bpp; это **не оригинальная палитра**;
- не публикует исходные байты и не сохраняет их в отчёте.

PNG создаётся стандартной библиотекой Python, без Pillow и без дополнительных зависимостей. Границы блока, полученные по следующему адресу, остаются только оценкой: это не доказательство длины изображения.

## 2. Первый эксперимент

Один кандидатный блок содержит **384 байта**. Для него проверены несколько математически допустимых интерпретаций:

| Предположение | Размер | Результат |
|---|---:|---|
| 4bpp | 24×32 | Получается связный силуэтоподобный рисунок в отладочной серой шкале |
| 4bpp | 48×16 | Получается другой рисунок с повторяющимися формами |
| 8bpp | 24×16 | Также проявляется структура, но палитра неизвестна |
| 16bpp RGB555 | 24×8 | Превью выглядит существенно менее убедительно |

Предварительное предпочтение — **4bpp**, вариант 24×32. Но это не считается декодированным спрайтом: несколько разных размеров/форматов дают структурированные изображения из одного и того же набора байтов. Без размеров из метаданных, правильной палитры и понимания адресации нельзя подтвердить, какая интерпретация верна.

Справка по аппаратуре: [VDP1 User's Manual — формат таблицы текстур и команда рисования](https://www.infochunk.com/saturn/segahtml_en/hard/vdp1/hon/p07_40.htm). Руководство допускает разные глубины цвета и хранение размеров в команде VDP1; оно не устанавливает формат конкретного файла игры.

## 3. Проверка

Добавлено 10 синтетических тестов: декодирование 4bpp с обоими порядками полубайтов, 8bpp, RGB555, проверка недостаточной длины, масштабирование и контроль PNG.

- Полный локальный набор: **76/76 тестов успешно**.
- `python -m compileall -q tools`: успешно.
- Реальный ISO использовался только локально.
- Все кандидатные PNG остаются локальными; репозиторий содержит только код и синтетические тесты.

Пример запуска на своей приватной копии:

```bash
python -m unittest discover -s tests -v
python -m compileall -q tools
python tools/stage08_texture_preview.py "/private/The Story of Thor 2.iso" \
  --container P0.BIN --element 0 --bpp 4 --width 24 --height 32 \
  --scale 6 -o /tmp/thor2-stage08-candidate.png
```

Для сравнения форматов можно повторить запуск с `--bpp 8 --width 24 --height 16` или `--bpp 16 --width 24 --height 8`.
