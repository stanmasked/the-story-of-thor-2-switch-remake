# The Story of Thor 2 — Stage 51: независимое подтверждение адреса загрузки SH-2

Дата: 22.10.2026.

## Новое свидетельство с оригинального диска

Ранее Stages 45–50 предполагали, что исполняемый модуль 0TH2.BIN имеет базу загрузки SH-2 0x06004000. Повторный анализ оригинального ISO с закреплённой SHA-256 обнаружил независимый источник этого адреса: поле 1st READ ADDRESS в заголовке IP.BIN Sega Saturn.

Подтверждены реальные значения:

| Поле оригинального диска | Значение |
|---|---|
| Saturn hardware ID | SEGA SEGASATURN |
| IP SIZE (offset 0xE0) | 0x1000, 4096 байт |
| 1st READ ADDRESS (offset 0xF0) | 0x06004000 |
| 1st READ SIZE (offset 0xF4) | 0 (для CD проигнорировано) |
| Первый обычный файл корневого ISO9660-каталога, FID 2 | 0TH2.BIN |
| Размер 0TH2.BIN | 535552 байта |
| Объявленный конец переноса | 0x06086C00 |
| Совместимость со статическими SH-2-ориентирами | 12 ролей Stage 45–46 |

В технической документации Sega Saturn адрес 1st-read destination задан по смещению 0xF0, а для CD файл с идентификатором [2] переносится во время экрана лицензии. Важное ограничение: **предварительно перенесённый файл не запускается автоматически**. Подтверждение назначения переноса не равно подтверждению исполнения в эмуляторе.

Справочные материалы: Sega Saturn Technical Bulletins — https://antime.kapsi.fi/sega/files/Sattechs.pdf ; Saturn DISC Format Standard — https://www.infochunk.com/saturn/segahtml_en/prgg/sofg/disc/hon/p04_10.htm

## Реализованная проверка

Новый tools/stage51_saturn_boot_first_read_map.py:

1. На приватном ISO сверяет SHA-256 со строгой закреплённой суммой Stage 46.
2. Извлекает поля IP SIZE, 1st READ ADDRESS, корневой каталог PVD ISO9660 и проверяет парные little/big-endian значения.
3. Проверяет служебные FID 0/1 (точка и родитель) и FID 2, который должен быть именно 0TH2.BIN.
4. Проверяет, что перенос первого файла не накладывается на IP, не пересекает верхнюю зарезервированную область WRAM-H и укладывается в выделенную память.
5. Сверяет содержимое первого файла со статическими сигнатурами копировщика Stage45 и шлюза Stage46, связывая файловую структуру с ранее найденными PC-ориентирами.
6. Возвращает агрегированную схему без оригинальных машинных байтов, файловых смещений, адресов отдельных инструкций и ресурсов.

Для локального запуска: python tools/stage51_saturn_boot_first_read_map.py --iso-private "/private/The Story of Thor 2.iso" --output-private "/private/stage51.private-boot-map.json".

Отчёт создаётся только новым файлом с правами 0600. Оригинальный ISO находится вне публичного репозитория. Для CI используются 28 синтетических тестов с искусственно построенными ISO9660-томами и SH-2-кодом.

## Исправленная модель счётчиков Stage 48–49

Повторная проверка Stage45 вскрыла прежнюю ошибочную трактовку вложенных циклов. **R2** уменьшается после копирования каждой 32-байтной команды (внутренний BF), а **R5** уменьшается только после завершения очередного 8-байтного дескриптора (внешний BF).

Корректный контракт: R5_before равен len(descriptors), количество скопированных 32-байтных команд равно sum(record.copy_count for record in descriptors).

Синтетический случай одного дескриптора с двумя командами теперь проверяется отдельно в Stages 48 и 49. Исправления проведены через ветки PR №46, №47 и №48, чтобы новые исследования не наследовали ошибочную формулу.

## Статус доказательств и следующий этап

**Доказано статически по оригинальному носителю:** заголовок и порядок каталога заявляют перенос 0TH2.BIN по адресу 0x06004000. Это сильнее, чем одиночный обратный вывод из констант SH-2-кода.

**Не подтверждено динамически:** успешный фактический перенос BIOS, изменение High Work RAM, исполнение функций, GPU-запись или связь с обработчиком №39. В текущем окружении не обнаружен эмулятор Saturn и нет подлинного снимка исполнения. Следующий этап — получить захват с воспроизводимым происхождением (образ, версия эмулятора, кадр, память, PC и VDP1 до/после).
