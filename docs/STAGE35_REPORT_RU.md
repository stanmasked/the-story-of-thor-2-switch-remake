# The Story of Thor 2 — Stage 35: найдена таблица косвенной диспетчеризации и tail-call в особую обёртку

Дата: 21.10.2026. Приватно проверен оригинальный Sega Saturn ISO MK-81302, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. В публичном репозитории нет образа, игровых машинных байтов, точных программных позиций и ресурсов.

## Исправление прежнего представления об обёртке

Stage 34 установил отрицательный результат для двух прямых механизмов входа в особую обёртку: `BSR` и PC-относительные `MOV.L` с её абсолютным адресом. Stage 35 обнаружил **отдельную последовательность передачи управления**: в особую обёртку ведёт **один SH-2 `BRA` из другой функции**. Это локальный tail-call-кандидат: перед BRA выполняются `MOV R14,R4` и восстановление PR, а в слоте задержки BRA — восстановление R14. При таком переходе регистр PR уже восстановлен для дальнейшего возврата из внутренней обёртки.

Эта внешняя функция, в свою очередь, обнаружена в непрерывном массиве указателей на исполняемый код. Связь подтверждена следующими статическими фактами:

| Проверка на оригинальном `0TH2.BIN` | Результат |
|---|---:|
| Полных связок «таблица → внешняя функция → BRA → особая обёртка → 7-байтовый читатель» | 1 |
| 32-битных элементов непрерывного массива адресов | 68 |
| Индекс внешней функции в массиве (с единицы) | 39 |
| Относительных BRA, направленных в особую обёртку | 1 |
| Абсолютных ссылок на внешнюю функцию в исполняемом модуле, big-endian | 1 |
| Абсолютных ссылок на внутреннюю обёртку в исполняемом модуле, big-endian | 0 |
| Вхождений адреса начала таблицы как 32-битного слова | 4 |
| Вхождений адреса выбранной ячейки таблицы как 32-битного слова | 4 |
| Инструкций MOV.L, способных прочитать PC-относительный литерал адреса начала таблицы | 9 |
| Инструкций MOV.L, способных прочитать PC-относительный литерал адреса ячейки | 8 |

Были проверены границы непрерывного массива: соседние слова интерпретируются как выровненные по 2 байтам адреса внутри известного региона исполняемого кода. Это делает гипотезу **таблицы указателей на функции** значительно сильнее, чем простое совпадение одного 32-битного значения.

Отдельный потоковый поиск по всему приватному ISO подтвердил одно big-endian вхождение адреса внешней функции и отсутствие такого вхождения для внутренней обёртки. Обнаружено также одно little-endian совпадение байтов адреса внешней функции **в другом участке образа**; это не основание считать его ссылкой на функцию без проверки контекста.

## Почему результат важен

Теперь имеется статическая цепочка с проверяемыми адресами назначения:

`массив 68 функций → элемент №39 → внешняя SH-2-функция → BRA с восстановлением R14 в delay slot → внутренняя обёртка с R5=2 → ранее распознанная процедура чтения +31…+37`.

Это **не утверждение**, что соответствующий элемент таблицы был выбран во время исполнения игры. Программа может иметь дополнительные условия выбора индекса, неиспользуемые пункты таблицы, другие способы передачи управления либо обработку ресурсов в иных ветках. Установленное назначение функции не доказывает, что она выдаёт готовые команды VDP1.

## Код, проверки и ограничения

- `tools/stage35_table_tail_link.py` — проверка внутреннего JSR в семибайтовый читатель, входящего BRA из внешней функции, регистров в слоте задержки, непрерывной таблицы адресов и PC-относительных ссылок на неё. Полный ISO сканируется потоково блоками, исходные данные не экспортируются.
- `tests/test_stage35_table_tail_link.py` — 29 синтетических тестов, включая границы таблицы, номер элемента, знак относительного перехода, передачу регистров, повреждённые связи, PC-relative MOV.L, проверку полного ISO в потоковом режиме и сокрытие оригинальных позиций.
- Инструмент не является универсальным дизассемблером SH-2 или контроллером выполнения. Лексический поиск MOV.L может включать недостижимые участки, а массив указателей может содержать неиспользуемые записи.
- Никакой графический формат, текстуры, палитры, спрайты или Nintendo Switch NRO не объявлены готовыми.
