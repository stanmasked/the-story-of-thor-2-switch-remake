# The Story of Thor 2 — Stage 17: аудит прямых вызовов производителя дескрипторов

Дата: 21.10.2026. Исследован приватный ISO Sega Saturn MK-81302. Репозиторий содержит только инструмент и синтетические тесты.

В файле 0TH2.BIN выявлена одна точка защитной проверки записи 8-байтового дескриптора с ёмкостью 512. Для неё проведены две независимые ограниченные проверки достижимости.

| Проверка | Результат |
|---|---:|
| Кандидатные точки производителя | 1 |
| Прямые BSR к найденной точке | 0 |
| MOV.L PC-relative ссылки на абсолютный адрес производителя (при базе 0x06004000) | 0 |
| Близкие JSR к регистру, загруженному таким литералом | 0 |

**Вывод:** отсутствие найденных ссылок не является доказательством неиспользуемого кода. Производитель может вызываться через арифметику адреса, таблицу указателей, JMP/JSR с загрузкой из памяти или из другого модуля. База 0x06004000 — гипотеза, перенесённая из Stage 15.

Исследование не подтвердило, что сдвинутый вправо на три бита аргумент всегда даёт одну копию. Предыдущее расхождение между числом дескрипторов и числом 32-байтовых записей остаётся открытым.

Добавлен tools/stage17_writer_callsite_audit.py и 7 синтетических тестов. Следующий шаг — распознавание адресной арифметики перед косвенными JSR/JMP и проверка реальных значений счётчиков при исполнении в эмуляторе. Необходимо избегать объявления графического декодера готовым до подтверждения командных структур и источника текстур.
