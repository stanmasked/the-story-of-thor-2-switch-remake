# The Story of Thor 2 — Stage 23: косвенные записи множителей VDP1 через указатели стека

Дата: 21.10.2026. Проверен оригинальный ISO Sega Saturn MK-81302, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. Оригинальные байты программы, файловые смещения и ресурсы остаются приватными.

## Что обнаружено

Stage 22 не выявил прямых записей в `[SP+20]` и `[SP+32]` в пределах поддерживаемых шаблонов. Новая проверка ищет последовательности `MOV R15,Rn`, `ADD #imm,Rn`, `MOV.B/W/L Rm,@Rn`: адрес локального поля вычисляется через временный регистр, а не используется прямое смещение от R15.

| Локальное поле | Кандидатных записей через R15-алиасы | Происхождение значений |
|---|---:|---|
| `[SP+20]` | 2 | Чтение байта `[R4+2]`; отдельная запись `(старое значение SP+20) AND 0x3F` |
| `[SP+32]` | 1 | Чтение байта `[R4+3]` |
| `[SP+56]` | 1 | Чтение байта `[R4+1]` |
| `[SP+80]` | 0 по этим шаблонам | Прямые записи уже выявлены на Stage 22 |

Всего найдены **четыре** различные точки записи через алиасы стека в исследуемой процедуре. Это объясняет, почему узкий детектор Stage 22 не видел заполнение обоих множителей.

## Связь с формулой

На Stage 20–21 подтверждена локальная арифметика `copies = (u8(SP+20) * u8(SP+32)) >> 3`, а флаг записи читается из `[SP+80]`. Теперь для начальных значений видны два источника — байтовые поля `[R4+2]` и `[R4+3]`. Применение маски `0x3F` к первому множителю обнаружено в отдельной последовательности, но **условие выполнения этого пути пока не восстановлено**.

Поэтому нельзя глобально ограничивать множитель 63 или считать, что структура R4 уже соответствует конкретному формату игровых ресурсов. Семантические смещения +1/+2/+3 относятся к памяти по R4, а не к смещениям внутри ISO.

## Изменения и контроль

- `tools/stage23_vdp1_stack_alias_provenance.py`: ограниченный анализ алиасов R15 и классификация источника записываемого байта.
- `tests/test_stage23_vdp1_stack_alias_provenance.py`: 15 полностью синтетических проверок; GitHub Actions запускает их без доступа к исходному образу.
- README и дорожная карта дополнены осторожной интерпретацией.

Детектор проверяет только короткие последовательности без известной перезаписи регистра-алиаса или управляющего перехода. Статическое обнаружение записи не доказывает достижимости при конкретном игровом событии. Возможны другие записи через вызовы, регистровые вычисления и непокрытые инструкции.
