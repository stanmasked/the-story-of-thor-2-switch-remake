# The Story of Thor 2 — Stage 114: точное окно возврата SH-2

## Основание

Stage113 дал две одинаковые по SHA-256 трассы оригинальной европейской игры: по 230 000 шагов каждая. В них зафиксированы 213 выборок BSR, 1 592 JSR и 1 801 RTS на сессию. Дополнительная сверка с открытым исходным кодом Mednafen уточнила, что старший байт Pipe_ID является селектором обработчика, а бит 0x80 используется при перекодировании инструкции в слоте задержки. Все выбранные BSR/JSR/RTS в этих двух трассах имели обычные селекторы соответствующих обработчиков.

Для BSR, связанного с целевым MOV.B в слоте задержки, найден один RTS, у которого входной PR совпадает с PR после BSR. Но в прежнем не-debug захвате наблюдаемый PC после RTS смещён на два байта относительно этого PR, а PC_ID/PC_IF не были доступны. Поэтому предыдущий результат — кандидат на возврат, а не полное доказательство.

## Что добавляет Stage114

Публичный патчер stage114_patch_mednafen_return_window.py выключен по умолчанию и добавляет короткое окно в debug-режиме Mednafen. Он не изменяет CPU-состояние намеренно; читает только доступные регистры, Pipe_ID/Pipe_IF и уже существующий прямой RAM-byte witness. Окно сохраняет:

- контекст перед целевым BSR и 32 шага вокруг вызова;
- нормальный селектор BSR и значение PR после вызова;
- следующий MOV.B в слоте задержки и изменение целевого байта;
- нормальный RTS с входным PR, совпадающим с PR целевого BSR;
- слот задержки RTS и следующие инструкции, чтобы подтвердить выбор и завершение шага инструкции на адресе возврата.

Публичный патчер содержит только универсальные селекторы SH-2 и не содержит адресов оригинальной игры, BIOS, бинарных ресурсов или сырых трасс. Окно ограничено 512 строками. Отдельный fail-closed gate выводит только безопасные счётчики и флаги.

## Условия принятия

Полный возврат по наблюдавшемуся пути засчитывается только если одновременно подтверждены нормальный BSR, MOV.B в его delay slot с изменением целевого RAM-байта, нормальный RTS с тем же PR, pipeline-совпадение слота задержки RTS, выбор и завершение шага инструкции по адресу возврата и совпадение PC_IF с ожидаемым return PC. Синтетический тест или RPC == PR без этих проверок не считается runtime-доказательством.

Даже если один наблюдавшийся путь будет подтверждён, это не докажет сохранение R13 на всех альтернативных путях Stage104. Оригинальный ISO, BIOS, адреса, регистры, байты RAM, сырые CSV, логи и конфигурации остаются только в owner-only Google Drive; для каждого файла обязателен SHA-256 и авторизованный readback.
