## 2. Сопоставление со второй секцией

В девяти контейнерах подтверждены **3 626 записей фиксированной длины 6 байт**.

Проверены оба кандидатных поля элементов против каждого из трёх 16-битных слов этих записей:

- Поле B (смещение 2): **совпадений не найдено**.
- Поле A (смещение 0): в файлах P0–P3 найдены редкие совпадения с третьим словом шестибайтовых записей — **31 вхождение элементов**, шесть разных числовых значений по четырём контейнерам. Есть и совпадения нулевого значения с первыми двумя словами; они могут быть просто маркером/значением по умолчанию.

Это слабая связь-кандидат, а не доказательство указателя или ссылки. В частности, частичные совпадения не позволяют присвоить полям смысл.

## 3. Другие наблюдения

- Два последних 16-битных поля восьмибайтовых элементов в десяти основных контейнерах имеют signed-диапазоны **−1 135…1 218** и **−514…236**. Они похожи на ограниченные числовые параметры, но считать их координатами пока нельзя.
- В первых 32 КиБ третьей секции десяти основных контейнеров энтропия находится в диапазоне **1,9068–4,9060 бит/байт**, доля нулей — **29,9–56,5%**. Это показывает выраженную структуру данных, но не доказывает несжатый графический формат.
- `MONS.BIN` и `P4.BIN` не проходят строгую грамматику Stage 04 и требуют отдельного разбора. Их выборки третьей секции имеют более высокую энтропию — примерно **7,1365** и **6,6110 бит/байт**.

## 4. Инструменты и проверка

`tools/stage05_field_profile.py` агрегирует частоты байтов, свойства 16-битных полей, выравнивание и совпадения между секциями. Отчёт не содержит точных последовательностей смещений или байтов ресурсов.

`tests/test_stage05_field_profile.py` содержит **13 тестов на синтетических данных**. Полный локальный набор: **44/44 теста успешно**. CI не требует ISO.

```bash
python -m unittest discover -s tests -v
python tools/stage05_field_profile.py "/private/The Story of Thor 2.iso" -o stage05.json
```

`stage05.json` исключён из Git. GitHub Actions предыдущего PR Stage 04 завершился успешно; проверка PR Stage 05 на момент обновления ещё выполнялась/ожидала runner.
