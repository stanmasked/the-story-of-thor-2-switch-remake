# The Story of Thor 2 — Stage 05: профилирование полей и связи секций

**Дата:** 21.10.2026. Анализ выполнен локально на приватном ISO Sega Saturn `MK-81302`, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. Оригинальные бинарные ресурсы не публиковались.

## 1. Кандидат на ссылку в третью секцию

В каждом восьмибайтовом элементе, который проходит грамматику Stage 04, исследовано 16-битное big-endian поле со смещением **2 байта от начала элемента** (байты 3–4 при нумерации с единицы).

В десяти контейнерах, целиком соответствующих грамматике Stage 04:

- **32 862 / 32 862** значений находятся внутри третьей секции с запасом минимум 8 байт;
- **32 545 / 32 862 (99,0354%)** кратны восьми;
- поле имеет **204 уникальных значения** на всех десяти контейнерах;
- часто повторяющиеся значения используются многими элементами.

Эти признаки согласуются с гипотезой относительного смещения или ссылки на данные третьей секции. Но поле может быть также идентификатором или упакованным значением. Поэтому публичный инструмент помечает его только как **кандидат на ссылку**, а не как доказанный указатель.

## 2. Сопоставление со второй секцией

В девяти контейнерах подтверждены **3 626 записей фиксированной длины 6 байт**.

Проверил, совпадают ли значения кандидатного поля из восьмибайтовых элементов с любым из трёх 16-битных слов каждой шестибайтовой записи того же контейнера. Результат: **0 совпадающих уникальных значений и 0 совпадений элементов**.

Это исключает простую прямую ссылку на одно из этих слов в проверенных шестибайтовых записях. Косвенная связь или другое кодирование всё ещё возможны.

## 3. Другие наблюдения

- Два других 16-битных поля в восьмибайтовых элементах имеют signed-диапазоны **−1 135…1 218** и **−514…236** в десяти контейнерах. Это могут быть координатоподобные или иные числовые параметры, но их назначение не доказано.
- В первых 32 КиБ третьей секции десяти основных контейнеров энтропия находится в диапазоне **1,9068–4,9060 бит/байт**, а доля нулей — **29,9–56,5%**. Такая статистика говорит о выраженной структуре данных, но сама по себе не доказывает, что это несжатая графика.
- `MONS.BIN` и `P4.BIN` не проходят строгую грамматику Stage 04. Для них нельзя применять ту же модель без дополнительного исследования. Их выборки третьей секции имеют более высокую энтропию — примерно **7,1365** и **6,6110** бит/байт соответственно.

## 4. Инструменты и проверка

Добавлен `tools/stage05_field_profile.py`: агрегирует частоты байтов, свойства 16-битных полей, диапазоны, выравнивание и возможные связи секций. Он не записывает в отчёт конкретные значения смещений или содержимое ресурсов.

Добавлен `tests/test_stage05_field_profile.py` с 12 тестами на синтетических данных. Полный локальный набор: **43/43 теста успешно**. Тесты не требуют ISO и не включают оригинальные данные игры.

Для повторного локального анализа:

```bash
python -m unittest discover -s tests -v
python tools/stage05_field_profile.py "/private/The Story of Thor 2.iso" -o stage05.json
```

JSON содержит только сводную статистику; `stage05.json` исключён из Git. GitHub Actions для предыдущего Draft PR на момент отчёта оставался в очереди, поэтому CI Stage 04 не объявляется завершённым.
