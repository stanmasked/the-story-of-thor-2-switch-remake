# The Story of Thor 2 — Stage 21: найдены три стэковых источника параметров загрузки VDP1

Дата: 21.10.2026. Проверен оригинальный приватный Saturn ISO MK-81302. В GitHub не публикуются оригинальные байты исполняемого кода, его файловые смещения и игровые ресурсы.

## Статическая цепочка

Непосредственно перед умножением двух беззнаковых байтов, обнаруженным Stage 20, найдена последовательность команд, загружающая:

- `MOV #20,R0` и `MOV.B @(R0,R15),R5`: первый байтовый множитель из адреса `SP+20`.
- `MOV #32,R0` и `MOV.B @(R0,R15),R3`: второй байтовый множитель из адреса `SP+32`.
- `MOV #80,R0` и `MOV.B @(R0,R15),R0`: условный байт-флаг из `SP+80`.

В последующих `EXTU.B`, `MULU.W`, `STS MACL`, `EXTU.W` и трёх `SHLR` подтверждена формула:

```text
per_source_copy_count = (u8(memory[SP+20]) * u8(memory[SP+32])) >> 3
writer_enabled = (signed_byte(memory[SP+80]) == 1) && (descriptor_count < 512)
```

Здесь SP — значение R15 **на момент этих конкретных инструкций**. Этап не выяснил, откуда три байта первоначально поступили в память стека: это могут быть предварительно скопированные параметры вызывающей стороны либо локально заполненные поля.

## Проверка

| Признак | Результат |
|---|---:|
| Полная цепочка загрузки стэковых множителей и Stage 20 на приватном ISO | 1 |
| Смещения множителей относительно R15 | +20 и +32 |
| Смещение байта-флага относительно R15 | +80 |
| Синтетические тесты Stage 21 | 10/10 |
| Синтетические тесты Stage 20 + Stage 21, локально | 23/23 |

Добавлены `tools/stage21_vdp1_stack_sources.py` и `tests/test_stage21_vdp1_stack_sources.py`; результат анализа содержит только агрегированные сведения и семантические смещения от указателя стека, не позиции внутри игрового бинарного файла.

## Дальнейшие задачи

1. Найти инструкции записи в слоты `[R15+20]`, `[R15+32]` и `[R15+80]` в окружающей процедуре.
2. Проследить, какие структуры определяют оба размера, как формируется индекс источника и что означает флаг.
3. Проверить реальные значения через эмуляторную трассу, особенно согласование количества дескрипторов с общим бюджетом загрузчика.
4. Только после подтверждения связать поля со структурой команд VDP1 и графическими контейнерами P0–P3.

**Граница доказательств:** подтверждены чтения параметров со стека и локальная формула. Их игровые значения и ресурсы остаются неизвестными. Декодер графики и запускаемый Switch NRO пока отсутствуют.
