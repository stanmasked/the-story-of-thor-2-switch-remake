# The Story of Thor 2 — Stage 22: аудит записи параметров VDP1 в стек SH-2

Дата: 21.10.2026. Исследован приватный образ Sega Saturn MK-81302 (SHA-256 25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d). Образ диска и игровые ресурсы не публикуются.

## Результат

В 0TH2.BIN перед последовательностью Stage 21 обнаружена сигнатура пролога с сохранением семи регистров и выделением 88 байт локальной памяти командой ADD #-88,R15.

Между этой операцией и загрузкой множителей выполнен консервативный поиск записей в стек. Узнаются только: непосредственный MOV #offset,R0 перед индексированным MOV.B/W/L Rm,@(R0,R15); MOV.L Rm,@(disp,R15); и MOV.B/W R0,@(disp,R15). Ширина записи учитывается: 16- или 32-битная операция может перекрывать искомый байт.

| Параметр | Результат |
|---|---:|
| Цепочек Stage 21 | 1 |
| Цепочек с выделением локального кадра 88 байт | 1 |
| Сохранений регистров в распознанном прологе | 7 |
| Прямых записей по распознанным шаблонам | 18 |
| Записей, охватывающих [SP+20] | 0 |
| Записей, охватывающих [SP+32] | 0 |
| Записей, охватывающих [SP+80] | 2 |

Байтовый флаг управления записью дескриптора имеет два прямых пути присваивания в рассматриваемом участке. Для обоих множителей формулы (A × B) >> 3 не обнаружены прямые присваивания в рамках узкого набора шаблонов.

**Это не доказательство отсутствия инициализации факторных полей.** Они могут записываться через указатели, результаты вызовов, вычисляемые индексы либо инструкции, которые текущий детектор не поддерживает. Отсутствие распознанных модификаций SP не доказывает полную стабильность указателя в произвольном коде.

## Реализация

- tools/stage22_vdp1_stack_store_audit.py — чтение приватного ISO и агрегированный аудит прямых записей.
- tests/test_stage22_vdp1_stack_store_audit.py — 14 синтетических тестов, включая отрицательные случаи, разную ширину записи, распознавание кадра и отсутствие исходных файловых позиций в отчёте.
- README и дорожная карта обновлены.
