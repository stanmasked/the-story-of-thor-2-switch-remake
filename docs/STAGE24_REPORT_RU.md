# The Story of Thor 2 — Stage 24: цикл обработки VDP1 и знаковый байтовый счётчик

Дата: 21.10.2026. Оригинальный образ Sega Saturn MK-81302 исследован локально. Репозиторий не содержит исходного ISO, игровых ресурсов, оригинальных машинных байтов и точных файловых позиций.

## Проверенный результат

В `0TH2.BIN` обнаружена одна полная узкая сигнатура: чтение байта `[R4+1]`, запись в `[SP+56]`, начало обработки записи и завершающая часть цикла. Последняя считывает `[SP+56]` как байт, вычитает единицу с 8-битным усечением, записывает результат обратно, считывает как знаковый байт и применяет `CMP/PZ`. Если результат неотрицателен, выполняется `BRA` к началу цикла; если отрицателен, `BF` пропускает обратный переход.

| Проверка | Результат |
|---|---:|
| Полных совпадений структуры на оригинальном ISO | 1 |
| Исходное поле счётчика | `[R4+1]` |
| Рабочее поле счётчика | `[SP+56]` |
| Ширина счётчика | 8 бит |
| Проверка выхода | знаковое значение после декремента меньше нуля |
| Обратный переход | `BRA` к подтверждённому началу обработки |
| Слот задержки обратного перехода | `NOP` |
| Тело цикла с операцией `AND 0x3F` | 1 |

Поскольку `BRA` выполняет свой слот задержки, наличие в нём `NOP` проверяется отдельно. Условная ветка `BF` в данном участке **не является задержанной**. Скрипт вычисляет цели переходов из знаковых относительных смещений вместо поиска совпадающих байтов без контроля адреса.

## Модель счётчика — отдельно от игровых наблюдений

Добавлена безопасная модель чистой арифметики байта, которая выполняет декремент с усечением по модулю 256 и проверяет знаковый результат. В ней начальное значение 0 приводит к одной итерации, 1 — к двум, 127 — к 128, 128 — к 129, 255 — к одной. Это **не измеренная длительность игрового цикла**: модель не учитывает другие записи, прерывания, нестандартные входы и вызываемые функции. Она нужна для выявления ошибок в знаковой арифметике наших будущих инструментов.

Операция `AND 0x3F` находится в распознанном теле цикла. Её наличие **не доказывает выполнение во всех ветвях**, поэтому глобальный предел первого множителя пока не установлен. Происхождение указателя `R4` остаётся открытым.
