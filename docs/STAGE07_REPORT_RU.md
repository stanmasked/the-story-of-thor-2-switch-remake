# The Story of Thor 2 — Stage 07: проверка адресов текстур и геометрических списков

**Дата:** 21.10.2026. Анализ выполнен локально на приватном ISO Sega Saturn `MK-81302`, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. В GitHub отправлены только анализатор, синтетические тесты и агрегированный отчёт; исходные ресурсы не публиковались.

## 1. Первое поле восьмибайтового элемента — кандидат на адрес текстуры

В десяти контейнерах, прошедших строгую проверку Stage 04, исследованы **32 862 элемента**. Первое 16-битное поле умножается на 8, после чего полученное смещение:

- даёт **32 832 из 32 832** ненулевых адресов, где доступны минимум 32 байта до конца третьей секции;
- выровнено на 32 байта во всех **32 832 из 32 832** случаев;
- имеет **13 587 из 13 587** промежутков между соседними уникальными адресами, кратных 32 байтам.

Суммарно по контейнерам обнаружено 13 597 уникальных ненулевых адресов. Эти данные значительно усиливают гипотезу, что поле хранит адрес текстурных данных в восьмибайтовых единицах: после умножения на 8 адреса соответствуют 32-байтовой границе. Руководство VDP1 описывает данные шаблонов символов с глубиной 4, 8 или 16 бит на пиксель и границей в 0x20 (32) байта: [VDP1 User's Manual — Character Pattern Table](https://www.infochunk.com/saturn/segahtml_en/hard/vdp1/hon/p02_20.htm).

**Ограничение:** это согласованность с аппаратным форматом, а не доказательство конкретного пиксельного формата игры. Размеры, палитра, порядок пикселей и сжатие ещё не установлены.

## 2. Второе поле — кандидат на список геометрических записей

В контейнерах `P0.BIN`, `P1.BIN`, `P2.BIN` и `P3.BIN` обнаружены 55 уникальных смещений, для которых первые 16 16-битных слов удовлетворяют строгому условию:

- присутствуют как минимум четыре ненулевых значения;
- каждое ненулевое значение указывает внутрь третьей секции;
- по адресу цели находится 14-байтовая запись, заканчивающаяся словом `0x7FFF`.

В этих префиксах проверены **498 ненулевых ссылок**, и все они указывают на записи с указанным маркером. Среди целевых записей, суммированных по четырём контейнерам, найдено **168 уникальных записей**; для **159 из 168 (94,64%)** следующая запись находится ровно через 14 байт. Первые шесть 16-битных слов этих записей, интерпретированные как signed, находятся в диапазоне **−63…70**.

Это похоже на таблицы ссылок на небольшие координатные/геометрические записи. Название «треугольники» пока остаётся рабочей гипотезой: маркер и длина записи сами по себе не доказывают семантику вершин или способ отрисовки. В шести остальных строгих контейнерах такой же тест не обнаружил кандидатов.
