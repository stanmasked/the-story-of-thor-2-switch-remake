# The Story of Thor 2 — Stage 30: поиск потребителей подготовленных полей +31…+37

Дата: 21.10.2026. Проверен только локальный оригинальный Sega Saturn ISO MK-81302 (SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`). Публичный анализатор не выводит точные позиции в бинарном файле, оригинальные программные байты, графику или звук.

## Что найдено

Этапы 27–29 восстановили запись семи байтов по относительным адресам +31…+37, в том числе знаковое Q8.8-преобразование. Теперь выполнен **независимый поиск читающих SH-2-последовательностей**: сочетания `MOV #field,R0` и `MOV.B @(R0,R4),Rn` для полей +31, +32, +33, +34 в строго возрастающем порядке, без распознанного перехода между ними. Удлинённая последовательность дополнительно проверяет байт +35 и `MOV.W @(R0,R4),Rn` для +36…+37.

| Тип найденного кандидата | Количество | Наблюдаемая обработка |
|---|---:|---|
| Набор четырёх байтов +31…+34 | 3 | Три разных участка SH-2-кода используют одинаковые относительные поля от R4 |
| Все семь байтов +31…+37 | 1 | Пять байтов и одно 16-битное слово |
| Четыре прибавления R5 к считанным значениям | 1 | Обнаружено по `ADD R5,Rn` для всех четырёх регистров |
| Четыре сложения с R6 и последующие 16-битные записи в стек | 1 | Обнаружено по `ADD R6,R0` и `MOV.W R0,@(disp,R15)` |

Сканер выявил **три** независимые статические группы на приватном исполняемом файле; **одна** из них читает весь семибайтовый набор. Обе разновидности арифметического использования встречаются по одному разу.

## Ограничения

**Наличие совпадающих смещений не доказывает тождество структуры.** В трёх разных участках `R4` может означать три объекта разного типа с похожей компоновкой. Текущий этап не реконструирует вызывающие цепочки, не доказывает достижимость инструкций во время игры и не связывает рассчитанные результаты с реальным буфером команд VDP1. Кодовым и числовым полям пока нельзя назначать игровые имена вроде «координаты спрайта» без подтверждения.

Текущий алгоритм является ограниченным синтаксическим поиском по инструкциям SH-2; он не заменяет полный дизассемблер и не отслеживает произвольные изменения регистра R4 между чтениями. Поэтому результаты рассматриваются как **кандидаты на потребление полей**, а не полная карта структуры.
