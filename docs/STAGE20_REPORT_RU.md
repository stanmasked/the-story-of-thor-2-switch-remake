# The Story of Thor 2 — Stage 20: восстановлена цепочка двух множителей для количества копий VDP1

Дата: 21.10.2026. Оригинальный Sega Saturn ISO (MK-81302, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`) проанализирован локально. Репозиторий содержит только сигнатурный анализатор, синтетические тесты и агрегированное описание. Байты оригинальной программы, её файловые смещения, текстуры, музыка и образ диска не публикуются.

## 1. Новый подтверждённый путь данных

Перед блоком Stage 19 в `0TH2.BIN` найдена непрерывная последовательность инструкций SH-2, которая:

1. С помощью двух `EXTU.B` очищает старшие биты исходных R5 и R3, оставляя по одному беззнаковому байту.
2. Использует `MULU.W R3,R5`, помещающий произведение в `MACL`.
3. Загружает байт из памяти по адресу `SP + 80` в R0 (комбинация `MOV #80,R0` и индексированного `MOV.B`).
4. Переносит `MACL` в R5 через `STS MACL,R5`.
5. Сравнивает извлечённый байт с единицей. При несовпадении `BF/S` ведёт к общему выходу; слот задержки всё равно выполняет `EXTU.W R5,R4`.
6. При разрешённой записи производитель Stage 19 копирует R4 в R2, трижды выполняет `SHLR R2` и записывает 16-битное число записей для копирования. Дополнительно проверяется свободное место в буфере на 512 дескрипторов.

Локальная формула, подтверждённая по инструкциям:

```text
A = unsigned_byte(R5_before_multiply)
B = unsigned_byte(R3_before_multiply)
per_source_copy_count = (A * B) >> 3
write_enabled = (signed_byte_at_SP_plus_80 == 1) AND (descriptor_count < 512)
```

Это уточняет Stage 19: R5, поступающий в вычисление количества, сам является произведением двух 8-битных множителей. Откуда пришли исходные значения множителей, статическая сигнатура пока не устанавливает.

## 2. Количественные результаты

| Измерение | Результат |
|---|---:|
| Совпадений полной цепочки на приватном ISO | 1 |
| Связанных с полным блоком Stage 19 | 1 |
| Ширина двух исходных множителей | 8 + 8 бит |
| Теоретически максимальное произведение | 65 025 |
| Теоретически максимальное количество 32-байтовых записей по формуле | 8 128 |
| Локальных синтетических тестов Stage 20 | 13/13 |

Математический предел 8 128 **не измерен во время работы игры** и не отменяет лимита 512 дескрипторов. Эти значения относятся к разным сущностям: полю числа копируемых блоков и ёмкости списка дескрипторов.

## 3. Проверки

`tools/stage20_vdp1_product_flow.py` выявляет полную сигнатуру умножения, передачу через MACL, байтовое условие и связанный блок Stage 19. `tests/test_stage20_vdp1_product_flow.py` содержит 13 полностью синтетических тестов на повреждение каждого ключевого звена, несоответствие ветки, недостающие сдвиги, граничные значения, отсутствие оригинальных смещений в отчёте.

Семантика инструкций сопоставлена с руководством Renesas SH-2E Software Manual, Instruction Set:
https://www.renesas.com/en/document/mah/sh-2e-software-manual

## 4. Следующие задачи

- Найти происхождение двух исходных байтовых множителей перед `EXTU.B` и выяснить связь с конкретными ресурсами.
- Проверить допустимые значения во время реального исполнения, особенно многоблочные дескрипторы.
- Восстановить точный смысл общего счётчика, который производитель увеличивает на один, а копировщик может уменьшать после 32-байтовой записи.
- После этого сопоставить входной адрес источника с командами VDP1 и контейнерами P0–P3.

**Статус:** подтверждена статическая арифметическая цепочка, но спрайты, палитры и игровой движок не восстановлены. Нативная сборка Nintendo Switch NRO пока не создана.
