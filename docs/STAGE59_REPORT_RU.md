# The Story of Thor 2 — Stage 59: приватная интерпретация цветовой памяти VDP2

Дата: 22 октября 2026 года.

## Что было проверено

Stages 57–58 определяют цветовой режим текстуры VDP1, размер и формат исходных texel-кодов, прозрачность, end-code и 16-цветные LUT. Но цветовой банк из CMDPMOD/CMDCOLR **не является RGB-цветом**: окончательный адрес цвета задаётся VDP2 с учётом регистра режима памяти, типа спрайта и смещения палитры.

Для Stage59 сверены именно первичные правила VDP2:

- [VDP2 User's Manual — 3.4 Color RAM mode](https://www.infochunk.com/saturn/segahtml_en/hard/vdp2/hon/p03_40.htm)
- [VDP2 User's Manual — 9.1 Sprite data](https://www.infochunk.com/saturn/segahtml_en/hard/vdp2/hon/p09_10.htm)
- [VDP2 User's Manual — 10.1 Palette-format dot color data](https://www.infochunk.com/saturn/segahtml_en/hard/vdp2/hon/p10_10.htm)

Размер аппаратной VDP2 CRAM составляет 4096 байт. Регистр RAMCTL по смещению 0x0E от начала VDP2-регистров (адрес 0x18000E в адресном пространстве самого VDP2) задаёт CRMD. Регистр SPCTL (+0xE0) задаёт SPTYPE и смешанный RGB/палитровый режим. Регистр CRAOFB (+0xE6) содержит SPCAOS в битах 6–4.

| Режим CRAM | Формат | Количество цветов |
|---|---|---:|
| 0 | 16-битный RGB555 | 1024 (две зеркальные области) |
| 1 | 16-битный RGB555 | 2048 |
| 2 | 32-битная запись, RGB888 | 1024 |
| 3 | Зарезервирован | Отклоняется |

По документации Saturn, при выводе компоненты RGB555 расширяются до 8 бит с тремя **нулевыми** младшими битами. Поэтому значение компоненты 31 даёт 248, а не 255. Для режима 2 в 32-битной записи извлекаются красная, зелёная и синяя компоненты по 8 бит.

## Реализация

Добавлены `tools/stage59_vdp2_cram_sprite_palette.py` и `tests/test_stage59_vdp2_cram_sprite_palette.py`.

1. Принимаются только **полные** приватные снимки VDP1 VRAM (524288 байт), VDP2 CRAM (4096 байт) и VDP2-регистров (512 байт). Их необходимо получить **одновременно из одного состояния эмулятора**.
2. Из регистров извлекаются CRMD, SPTYPE, SPCLMD, SPCAOS и признак коэффициентной таблицы. Все 16-битные/32-битные значения читаются в big-endian.
3. Поддержано чтение отдельных CRAM-записей режимов 0, 1 и 2 в приватную память без записи этих цветов в публичный JSON.
4. Для *палитровых* значений Stage58 поддержаны типы спрайта 0–7 по задокументированной ширине поля цветового кода. Для режимов CRAM 0/1 вычисляется 11-битный адрес палитры с учётом SPCAOS (шаг 0x200); для режима 0 старший бит итогового адреса игнорируется. При включённой коэффициентной таблице не вычитываются сомнительные записи второй половины режима 1.
5. Для смешанного режима SPCLMD, если установлен старший бит кадрового значения, код отдельно рассматривается как **кандидат прямого RGB555**, без объявления результата окончательным изображением.
6. В целях точности пока **не утверждается** адресация цветового банка спрайта в режиме CRAM 2 и не декодируются альтернативные типы 8–F восьмибитного буфера кадра. Такие случаи явно получают категорию `unresolved`.

Поскольку VDP2 может трактовать пиксель как тень, приоритет, условие цветового смешивания или служебный код, полученный RGB объявляется **candidate**, а не пикселем отрисованного кадра. Полноценное воспроизведение compositor не реализовано.

## Запуск

Статическая проверка неизменённого приватного оригинального ISO без дампов:

```sh
python tools/stage59_vdp2_cram_sprite_palette.py \
  --iso-private "/private/The Story of Thor 2.iso"
```

Для закрытого набора трёх синхронных захватов:

```sh
python tools/stage59_vdp2_cram_sprite_palette.py \
  --iso-private "/private/The Story of Thor 2.iso" \
  --vdp1-vram-private "/private/capture/vdp1.private-vram" \
  --vdp2-cram-private "/private/capture/vdp2.private-cram" \
  --vdp2-regs-private "/private/capture/vdp2.private-registers" \
  --output-private "/private/capture/stage59.private-palette-audit.json"
```

Отчёт создаётся как новый файл с правами 0600. В нём содержатся только агрегированные количества кодов и безопасные режимы, без адресов отдельных пикселей, оригинальных RGB-значений, изображений или исходных данных CRAM.

## Проверки и следующий этап

Добавлены **48 синтетических тестов**: три CRAM-режима, отказ от режима 3, точная RGB555/RGB888 арифметика, смещения SPCAOS, варианты SPTYPE 0/4/7, разделение смешанного RGB и палитр, незавершённые аппаратные режимы, обработка повреждённых данных и приватность JSON.

Оригинальный пользовательский ISO локально повторно проверен: 106954752 байта, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. Он не загружался в GitHub.

**Ни один подлинный набор VDP1 VRAM + VDP2 CRAM + VDP2 registers из работающего Saturn ещё не получен.** Следовательно, этот этап подтверждает аппаратно обоснованный анализатор, но не восстановление настоящей палитры The Story of Thor 2. Следующий приоритет — достоверный захват, проверка трактовки shadow/priority и работа нативного графического слоя только после получения реальных данных.
