# The Story of Thor 2 — Stage 42: аргументы диспетчеризации и контракт трассировки клонированного объекта

Дата: 22.10.2026. Приватно исследован Sega Saturn ISO MK-81302, SHA-256 `25b0b2774d4621bd9f95a01fc5420ded37b481b61b3cdf515360d82b2cb7bb0d`. Исходные машинные байты, абсолютные позиции в игровом коде, сам ISO, графика и звук не опубликованы.

## Продвижение от Stage 41

На Stage 40 найдена процедура клонирования 276-байтной структуры в один из 43 слотов общего пула с заменой поля индекса `+126` на значение 38. Stage 41 обнаружил четыре независимых участка, использующих тот же пул и тот же размер записи. Stage 42 проверил два **входа функций**, внутри которых находятся индексированные переходы через отдельную 68-элементную таблицу обработчиков.

Оба входа имеют SH-2-прологи, включающие `MOV R4,R14`: переданный извне указатель R4 сохраняется в R14, из которого затем читается `[R14+126]` для выбора функции. Но это **не доказывает**, что R4 указывал на слот Stage 40.

| Проверка оригинального исполняемого кода | Результат |
|---|---:|
| Найдено подписанных индексированных диспетчеризаций через таблицу из 68 адресов | 2 |
| Из них с распознанным входным `MOV R4,R14` | 2 |
| Статических прямых `BSR` в два распознанных входа | 0 |
| Статических прямых `BRA` в эти входы | 0 |
| Условных прямых переходов в эти входы | 0 |
| PC-относительных `MOV.L`, загружающих точные адреса этих входов | 0 |
| Подтверждённых runtime-переходов от копии с индексом 38 к диспетчеризации | **0 (не наблюдалось)** |

Отрицательные результаты относятся только к распознаваемым прямым формам ссылок. Другие точки входа, таблицы указателей, вычисляемые цели и косвенные переходы ими не исключаются. Нельзя трактовать эти нули как доказательство недостижимости функций.

## Реализован контракт для будущей трассы Saturn-эмулятора

Файл `tools/stage42_pool_dispatch_trace_contract.py` выполняет две независимые операции:

1. **Статический аудит** исходного ISO: повторно устанавливает таблицу 68 функций, общий пул 43×276 байт, сверяет два пролога диспетчеризации и ограниченно ищет ссылки на их входы. Результат содержит только числовые агрегаты.
2. **Проверка представленной последовательности событий** (опциональный `--trace-json`): четыре события одного символического объекта — `slot-selected` → `object-cloned` → `index-written` → `table-dispatched`.

Контракт требует, чтобы слот имел номер от 0 до 42, размер копии составлял ровно 276 байт, записываемое поле имело смещение 126 и значение 38, а диспетчеризация выбрала функцию №39. Для обращения от начала таблицы индекс должен быть 38; для обращения от ячейки №39 — индекс 0. Все события должны иметь одинаковые `object_id` и `slot`, с правильным порядком.

### Искусственный пример формата (не игровой захват)

```json
{
  "events": [
    {"kind": "slot-selected", "slot": 3, "object_id": "synthetic-A"},
    {"kind": "object-cloned", "slot": 3, "object_id": "synthetic-A", "copied_bytes": 276},
    {"kind": "index-written", "slot": 3, "object_id": "synthetic-A", "field_offset": 126, "index": 38},
    {"kind": "table-dispatched", "slot": 3, "object_id": "synthetic-A", "anchor": "table_start", "index": 38, "selected_slot_one_based": 39}
  ]
}
```

Запуск по приватному образу и приватному журналу:

```bash
python tools/stage42_pool_dispatch_trace_contract.py "/private/The Story of Thor 2.iso" --trace-json /private/trace.json -o /private/stage42.json
```

**Важно:** даже успешно пройденный контракт — лишь внутренняя согласованность **переданных событий**, а не подтверждение, что события действительно записаны настоящим Saturn-эмулятором. Скрипт не обращается к эмулятору, не удостоверяет происхождение журнала и никогда не выставляет `runtime_proven_by_checker=true`. Приватные идентификаторы объектов и адреса из журнала не включаются в итоговый агрегированный JSON.

## Тестирование и следующий этап

- `tests/test_stage42_pool_dispatch_trace_contract.py`: синтетические проверки двух прологов, форм прямых ссылок, входных предпосылок, 43×276, правильного выбора ячейки №39, границ слота и многочисленных ошибок последовательности событий.
- Не утверждается, что реальная трасса уже существует. Нет доказательства записи команд VDP1, формата спрайтов, пиксельного декодера или запускаемой Nintendo Switch NRO.

Stage 43: получить приватную трассу исполнения Saturn-эмулятора, зарегистрировать адрес выделенной записи и передачи R4/R14 к двум диспетчерам, убедиться в выборе функции №39 по фактически записанному значению +126. Если выбор подтверждён, продолжить трассировку до VDP1-команд; иначе вернуться к поиску других обработчиков копии.
